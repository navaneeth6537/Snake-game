🐍 Snake Game

A simple Snake Game developed using Python and Pygame.

The player controls the snake using the arrow keys, collects food to increase the score and grow the snake, and must avoid hitting the walls or itself.

🎮 Features

- 🐍 Snake movement using arrow keys
- 🍎 Food collection
- 📈 Score tracking
- 🐍 Snake grows when food is collected
- 💥 Wall collision detection
- 💥 Self-collision detection
- 🔊 Eating sound effect
- 🎵 Background music
- 🖼️ Custom graphics for the snake, food, and background
- ▶️ Start menu
- 🔄 Restart option after Game Over
- ❌ ESC key to quit

🕹️ Controls

Key| Action
⬆️ Up Arrow| Move Up
⬇️ Down Arrow| Move Down
⬅️ Left Arrow| Move Left
➡️ Right Arrow| Move Right
SPACE| Start / Restart
ESC| Quit

▶️ How to Run

1. Install Python

Make sure Python is installed on your computer.

2. Install Pygame

Open a terminal or command prompt and run:

pip install pygame

3. Run the game

Open the project folder and run:

python snake_game.py

Make sure the "assets" folder stays in the same project directory as "snake_game.py".
